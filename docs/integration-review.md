# PR 整合审查与验收记录

检查日期：2026 年 10 月 23 日。范围为 PR #1 的统计服务与部署，以及 PR #2 的反馈服务与数据库；依据老师的项目要求和 `docs/team-agreement.md`。

## 审查发现与处理

1. 两个 PR 同时新增 `docker-compose.yml`、`.env.example`、`.gitignore`，存在合并冲突。PR #2 的 Compose 只有反馈和数据库；整合保留 PR #1 的三服务配置、内部 `db:5432` 连接、6110/6111 端口、健康检查和持久化卷，接入 PR #2 的正式源码及建表脚本。
2. 数据库镜像统一使用整体部署原定的官方 `postgres:17.6-bookworm`。使用全新测试数据卷验证，没有将 PostgreSQL 16 的既有数据目录直接交给 17，也没有删除或迁移既有用户数据。
3. 反馈依赖原先没有版本约束，现固定为此次实际构建使用的 Flask 3.1.3 和 psycopg 3.3.6。修正数据库连接注释中的 MySQL 名称为 PostgreSQL。
4. README 和部署说明仍称反馈代码尚未交付，且默认引导独立统计环境。现改为以 `main` 的完整系统部署为主，并保留独立开发说明。
5. 新增 `scripts/test-full-stack.py`，将真实三容器验收保存为可重复执行的脚本。

反馈后端使用参数化 SQL，在事务提交成功后输出难度与主题；数据库约束覆盖难度范围、主题取值和必填。统计在一条 SQL 中计算所有指标，连接默认只读，查询失败返回 503，空表不显示虚假的平均分。

环境：Apple Silicon Mac、Docker Desktop 的 Linux 容器、Docker Engine 29.7.2、Docker Compose v5.4.0。使用随机项目 `cisc7403-test-8c9ba3dde2e0`、临时随机密码和全新数据卷，从正式 `docker-compose.yml` 构建并启动服务。
